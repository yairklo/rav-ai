# textnorm

Normalization, acronym detection and citation parsing for rabbinic Hebrew/Aramaic text
(with or without niqqud). Standalone, no runtime dependencies. Python >= 3.11.

```powershell
cd packages/textnorm
uv sync
uv run pytest
uv run ruff check .
```

## API

```python
from textnorm import normalize, find_acronyms, find_citations, parse_numeral, to_gematria
```

### `normalize(text, level="A", *, plene="double") -> NormResult`

`NormResult.text` is the normalized text, `NormResult.spans[k] = (start, end)` is the half-open
range of the *original* string (code points) that produced `text[k]`.

* **Level A**: removes niqqud, cantillation, CGJ, bidi/zero-width/control chars; folds final
  letters (ך→כ ...); unifies maqaf/dashes → `-`, all geresh-like marks → `'`, all gershayim /
  double-quote-like marks → `"`; collapses and trims whitespace; NFKC-folds presentation forms
  (e.g. U+FB2A) and NBSP; lowercases non-Hebrew letters.
* **Level B**: A, plus punctuation removal (`'` `"` vanish without splitting the word, so `ר"ל` →
  `רל`; every other punctuation/symbol becomes a space) and plene/defective folding via `plene`:
  * `"double"` (default): collapses doubled ו/י (`מצווה`→`מצוה`, `ייתכן`→`יתכן`). Practically
    lossless.
  * `"vav"`: additionally drops a medial ו in words of ≥4 letters (`כתוב`→`כתב`). Lossy
    (`מצוה`→`מצה` collides with matzah), opt-in.
  * `"none"`.

`NormResult.map_span(norm_start, norm_end) -> (orig_start, orig_end)` returns the smallest
original slice covering the range; niqqud attached to the last letter is included.
`original_slice(a, b)` returns that substring. Empty ranges map to an empty range; out-of-range
raises `ValueError`.

```python
r = normalize("תָּנוּ רַבָּנַן: מִצְוַת חֲנוּכָּה נֵר אִישׁ")
i = r.text.index("מצות חנוכה")
s, e = r.map_span(i, i + len("מצות חנוכה"))
```

### `find_acronyms(text) -> list[AcronymCandidate]`

Finds words with gershayim (`ר"ל`, `ע"כ`, `מ"מ`, `וע"כ`, `בכ"ה`) and geresh abbreviations
(`סי'`, `וכו'`). Each candidate has `span` (original), `kind`, `prefix` (clitic ו/ה/ב/כ/ל/מ/ש/ד
stripped to match the dictionary), `expansions` (possible openings, each with `domain` and
`source`), and `could_be_numeral` (`כ"א`, `בכ"ה` also read as numbers). It never rewrites the
text. Geresh-ended words are reported only if in the dictionary or ≤2 letters, otherwise a closing
single quote would be indistinguishable.

### `find_citations(text, *, context=None) -> list[Citation]`

Returns `Citation(span, text, id, confidence, kind, parts)`; `id` is a Sefaria ref.

| Input | id |
|---|---|
| `שבת כא ע"ב` / `שבת דף כ"א:` | `Shabbat 21b` |
| `או"ח סי' תרע"א ס"ב` | `Shulchan Arukh, Orach Chayim 671:2` |
| `משנ"ב סי' תרע"א ס"ק ג` | `Mishnah Berurah 671:3` |
| `רמב"ם הל' חנוכה פ"ג ה"א` | `Mishneh Torah, Scroll of Esther and Hanukkah 3:1` |
| `משנה ברכות פ"א מ"א` | `Mishnah Berakhot 1:1` |
| `דף כ"א ע"ב` + `context="Shabbat"` | `Shabbat 21b` (without context: `id=None`) |

`confidence` is a heuristic in [0, 1] (explicit amud, "דף", explicit work name raise it; a bare
`שבת כא` scores lower). `parse_numeral` / `to_gematria` handle Hebrew numerals (canonical
spelling only: `כא` yes, `בא` no; `ט"ו`/`ט"ז`; thousands as `ה'תשפ"ד`).

## Data and sources

* `data/sefaria_titles.json`: canonical Sefaria titles (identifiers only, no texts) for Bavli (37),
  Mishnah (63), Mishneh Torah (83), Shulchan Arukh parts, Mishnah Berurah. Generated by
  `tools/build_titles.py` from `https://www.sefaria.org/api/index`.
* `data/acronyms.json`: 155 entries, each with `domain` and `source`. Source `curated-v1` = hand
  curated from standard usage; **no third-party dictionary was copied**. Dicta and Wikisource
  abbreviation lists were *not* imported because their license terms were not verified (Wikisource
  content is typically CC BY-SA, share-alike). To add one, put it in a new `sources` entry with its
  license and append entries.

## Known limitations

* Offsets are code points of the Python string, not UTF-16/bytes.
* A one-character span can cover several output chars (NFKC expansions) and spans of dropped
  marks are folded into the preceding letter; an empty normalized range has no original extent.
* Final-letter folding makes `ם`/`מ` (etc.) equal: good for matching, wrong for display; always
  show the original text via `map_span`.
* Level B drops all quote characters, including real quotations; ר"ל and רל become identical.
* Plene folding is context-free (no morphology); see `plene="vav"` collisions.
* Gershayim inside a word are never treated as numerals/acronyms when the quote is missing
  (`רשי`, `ריש לקיש` abbreviations without marks are not detected).
* Acronyms: many are ambiguous (`ר"י`, `ע"ב`); all candidates are returned, none chosen. Numerals
  like `כ"ה` appear as candidates with `could_be_numeral=True`.
* Citations: no Tanakh, Yerushalmi, Tur, Rema/Shakh/Taz sub-refs, ranges (`כא ע"א - כב ע"ב`),
  nor `מ"ב` used for other works; `ס"ב` after a siman is read as seif 2, never as 62; `שבת כא.`
  with a period is read as amud a with lower confidence; tractate names that are also ordinary
  words (שבת, ברכות) require a following numeral. Daf numbers are only range-checked to 2–176, not
  per tractate. Sefaria titles come from the index at generation time and may drift.
* A prefix letter attached to a work/tractate (`בשבת`) is part of the returned span.
